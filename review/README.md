# Manuscript review editions

[0.1.0 draft](0.1.0-draft/manuscript.pdf) is the current template-backed review
candidate. Its [readiness record](../docs/review-readiness.md) names the exact
core, template, input and output hashes and the actual technical review.

Read the PDF directly, or serve the complete draft directory locally and open
web/index.html. Keep the complete offline asset and figure tree together.
manuscript.html retains the earlier entry URL as a redirect.

The packet contains authored/hydrated source, bibliography, claim ledger,
source-bound evidence, corpus CSV/JSON, three figure sets, conceptual cover,
native template provenance and a complete byte inventory. New source, seed,
policy, dependency or renderer bytes require a rebuilt and renewed review.
Prior editions remain in Git history and retained build diagnostics.
No formal release, tag or DOI is created by a review packet.
