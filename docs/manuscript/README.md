# Davis 0.1 review manuscript

This is a Davis-specific software case study with its own claim ledger and
accepted municipal evidence. Numbered sources are authored here; shared methods
come from the frozen region-intel dependency. Version 0.1.0 is a manuscript
review target, separate from the application's package version and any release.

Run `bun run manuscript:check`, `bun run manuscript:render` and
`bun run manuscript:validate-render`. The ignored `output/manuscript-review/`
contains the native PDF/HTML, hydrated sources and exact evidence/render receipts.
Do not edit generated members. Read the readiness record and inspect the native
PDF before presenting a revision for review. No DOI, tag or release is created by
rendering. Final authorship/declarations, rights and publication remain separate.
